# App Icon (Orbit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Vite placeholder favicon/PWA icons and the rail's globe logo with the Orbit mark.

**Architecture:** One 24-unit glyph (orbit ellipse masked around a bead, plus a host dot) is the source
of truth. The rail renders it as an `IconLogo` React component in `components/icons.tsx`; the
favicon/app icons are hand-written SVG masters in `frontend/public/`; PNG fallbacks are exported
from those masters with Inkscape. Spec: `docs/superpowers/specs/2026-09-26-app-icon-design.md`.

**Tech Stack:** React 19 + Vite, Vitest + Testing Library, Inkscape 1.4 CLI (PNG export).

## Global Constraints

- Glyph: ellipse `cx=12 cy=12 rx=9.5 ry=4.5 transform="rotate(-35 12 12)"` stroke 2; bead `circle cx=19.8 cy=6.5 r=2.1` filled; host `circle cx=12 cy=12 r=2.4` filled.
- Gap mask: white `rect 24×24` + black `circle cx=19.8 cy=6.5 r=3.8`, `maskUnits="userSpaceOnUse" x=0 y=0 width=24 height=24`.
- The mask goes on a wrapping `<g mask>`, NEVER on the rotated ellipse. The `<mask>` carries `stroke="none"`.
- Colors: Tether Blue `#3b82f6`, navy `#0b0f1a`, dark border `#2f3b58`, light border `#d5dbe8`, white `#fff`.
- No production `<svg>` outside `components/icons.tsx` (repo convention).
- Frontend gates: `npm test` (vitest + oxlint) AND `npx tsc --noEmit -p tsconfig.app.json` (npm test does not type-check).

```tsx
// Brand mark: a record (bead) held on an orbit around the host (center dot).
export function IconLogo(p: IconProps): JSX.Element {
  const gap = useId();
  return (
    <Svg {...p}>
      <mask id={gap} maskUnits="userSpaceOnUse" x="0" y="0" width="24" height="24" stroke="none">
        <rect width="24" height="24" fill="#fff" />
        <circle cx="19.8" cy="6.5" r="3.8" fill="#000" />
      </mask>
      <g mask={`url(#${gap})`}>
        <ellipse cx="12" cy="12" rx="9.5" ry="4.5" transform="rotate(-35 12 12)" />
      </g>
      <g fill="currentColor" stroke="none">
        <circle cx="12" cy="12" r="2.4" />
        <circle cx="19.8" cy="6.5" r="2.1" />
      </g>
    </Svg>
  );
}
```
